Main flow still:

1. `begin_pipeline_run`

## 3. Phase 2 — Unit tests

**Required path:** `tests/pipelines/test_pipeline.py` (repo root, not `services/api/tests/`).

### 3.1 What to test

Unit-test **at least three** transformation units that compute CONTEXT KPIs. Call `data.process` / `transform_clinic_month_impl` (or `task.fn`) — **not** the extract/load tasks.

| Suggested test name | Unit | Assert |
| --- | --- | --- |
| `test_inbound_event_cost_prefers_total_cost` | `inbound_event_cost` | `total_cost` wins over `unit_cost × qty` |
| `test_supply_cost_per_clinic_hand_calculated` | `compute_clinic_month_kpis` | See §3.2 |
| `test_supply_consumption_volume_counts_outbound_only` | same | outbound count; inbound does not increment it |
| `test_critical_stockout_frequency_counts_threshold_events` | same | `stock_threshold_triggered` count |
| `test_expiry_risk_count_counts_flagged_batches` | same | `supply_expiry_flagged` count |
| `test_transform_drops_unknown_clinic_and_country_mismatch` | same | defensive / malformed |

Cover all four CONTEXT KPIs. Existing `services/api/tests/test_reporting.py` stays; do not move it.

### 3.2 Hand-calculated fixture (mandatory)

In-memory events only — no engine, no HTTP, no Prefect server.

Use HealthCore shape: `timestamp`, `event_type`, `value`, `tags` with `clinic_id` (int 1–12), `country`, `eventId`, and cost fields on inbound.

Example (August 2026, clinic **2** = Austin North):

| event | tags | contribution |
| --- | --- | --- |
| inbound | qty 10, `unit_cost` 12.50, `eventId` A | 125 |
| inbound | **same** `eventId` A (duplicate flush) | ignored |
| inbound | qty 4, `unit_cost` 20, `eventId` B | 80 |
| outbound × 2 | `eventId` C, D | consumption 2 |
| `stock_threshold_triggered` × 1 | | stockout 1 |
| `supply_expiry_flagged` × 1 | | expiry 1 |

**Expected Austin North row:** `total_supply_cost == 205.0`, `supply_consumption_count == 2`, `critical_stockout_count == 1`, `expiry_risk_count == 1`, `currency == "USD"`, `clinic_id == "austin-north"`.

Add one UK inbound (`clinic_id` 10, `total_cost` 24) and assert `london-city` / `GBP` / 24 — and that no test sums 205+24.

### 3.3 Defensive case (mandatory)

At least one of:

- missing / null `clinic_id` → row dropped
- `clinic_id` 99 → dropped
- clinic 2 with `country: "UK"` → dropped
- inbound with no `unit_cost` / `total_cost` → cost 0, `missing_inbound_cost_count` increments
- non-dict `tags` or bad timestamp → skipped, no exception

### 3.4 How tests must run

```bash
# from repo root, after uv sync --group dev
python -m pytest tests/pipelines/test_pipeline.py
# equivalent (recommended in this repo):
uv run python -m pytest tests/pipelines/test_pipeline.py
```

Root `pyproject.toml` has no pytest today. Add a **dev** group (`pytest>=8`) and `[tool.pytest.ini_options]` with `pythonpath = ["."]` and `testpaths` including `tests/pipelines`. Do not require FastAPI, Supabase, or `inventory_client`.
